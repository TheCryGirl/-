- 改动文件：仅 `src/web/src/views/BrowseHistory.vue`；证据目录为本目录

## 实现要点

| 项 | 实现 |
| --- | --- |
| 列表 | 保留原列表式历史卡片、`historyId` key、后端返回顺序与 `visitedAt` 展示，未改表格、未新增批量选择 |
| ID | 跳转与删除仍使用 `productId`，逐项忙状态也按 `productId` 记录 |
| 失效商品 | 保留置灰图片、「商品已下架」文案与禁止跳转 |
| 数量 | 原原生 select 改为 `el-select`，仍为最近 10/20/50 条，切换即重新加载；加载中禁用避免竞态 |
| 确认 | 单项删除与清空均接 `confirmAction`；原文案「删除「标题」的浏览记录？」「清空全部浏览足迹？」，取消/ESC 零写请求 |
| 成功 | `isOk` 判断 Result<Void> 后：单项从本地列表按 `productId` 过滤并提示；清空将列表置空并提示 |
| 失败 | 业务/HTTP 失败提示后端 message，保留原列表，不先删本地数据 |
| 三态 | 加载用 `el-skeleton`；失败用 `el-result` + 重试，不与空态混用；空列表用 `el-empty` + 「去商品市场看看」；失败时头部不显示数量 |
| 清空按钮 | `el-button` loading + 列表为空/加载中/清空中禁用 |
| testid | `history-remove-<productId>`、`history-clear`、`history-limit`、`history-retry` |
| 未改 | API、store、router、公共组件、依赖与锁文件、其他页面 |

## 验证记录

本地 mock 提供 8 条足迹（含 1 条失效），仅用于开发验证。

| 场景 | 操作 | 结果 |
| --- | --- | --- |
| 生产构建 | `pnpm run build` | 通过（vite 8.3.4，971ms） |
| 初始渲染 | 打开 `/history` | 8 条，顺序与接口一致（2026-10-20 → 10-13），失效商品有文案；控制台无告警；见 [1440 截图](images/f04-history.png) |
| 数量切换 | 由「最近 20 条」改为「最近 10 条」 | 发出 `GET /api/history?limit=10`，列表与文案正常 |
| 删除取消 | 点「删除」后点「取消」 | 弹窗文案「删除「纯色卫衣」的浏览记录？」；无 DELETE 请求、8 条不变 |
| 删除确认 | 再次删除并确认 | `DELETE /api/history/p-009` 200，列表 7 条，提示「已删除浏览记录」 |
| 清空取消 | 点「清空足迹」后点「取消」 | 无 DELETE 请求，7 条不变 |
| 清空确认 | 再次清空并确认 | `DELETE /api/history` 200，列表 0 条，显示空态，清空按钮禁用，提示「已清空浏览足迹」 |
| 加载失败 | mock 返回 500 | 显示 `el-result`「加载浏览足迹失败」+ 后端文案 + 重试；空态不出现；头部数量隐藏；见 [截图](images/f04-history-error.png) |
| 失败重试 | 恢复 mock 后点「重试」 | 重新 GET 成功，恢复 8 条 |
| 空态 | mock 返回空列表 | 显示 `el-empty`「还没有浏览记录」+「去商品市场看看」；见 [截图](images/f04-history-empty.png) |
| 写失败 | mock 对 DELETE 返回 500 | 提示「删除失败（模拟）」，8 条不变 |
| 失效商品 | 点击「防风夹克」行 | 路由仍为 `/history` |
| 正常跳转 | 点击「轻量跑鞋」行 | 路由为 `/products/p-010`，商品 ID 正确 |
| 响应式 | 360/768/1920 宽 iframe 实测 | 主内容分别无溢出（`main.scrollWidth` 345/753/1280）；360 下数量/清空换行、行内容完整；见 [360 截图](images/f04-history-360.png) |
| 控制台 | 三个页面加载与操作 | 仅 Vite 连接日志，无 Vue 告警或报错 |

## 未测与风险

- 未接真实 history 服务：真实记录顺序、失效字段、401 未实测。
- 无头/隐藏视口下 Element Plus 弹窗离场动画不结束，DOM 会暂时残留；已用 DOM 点击与网络请求验证行为，真实浏览器动画待评审复核。
- 360px 下公共 `AppHeader` 自身横向溢出（文档 `scrollWidth` 394），属于既有共享文件问题；本页主内容与列表行均未溢出，未改 AppHeader。

# 一键启停

管理本地服务的启动与停止。**后台进程不会因为关掉 DSH、关掉终端、重启电脑而自动恢复**，用这个脚本统一管理。

## 快速开始

```bat
cd src\scripts
dev.bat start        启动全部
dev.bat status       看谁在跑
dev.bat stop         全部停止
```

双击 `dev.bat` 也能用（会停在窗口里显示结果）。

## 命令一览

| 命令 | 作用 |
| --- | --- |
| `dev.bat start` | 启动全部：Nacos → 网关 → 各业务服务 |
| `dev.bat stop` | 停止全部，先停业务服务，最后停 Nacos |
| `dev.bat restart` | 重启全部 |
| `dev.bat status` | 显示端口、状态、PID，以及 Nacos 已注册的服务 |
| `dev.bat logs` | 列出日志文件与大小 |

### 只操作某个组件

```bat
dev.bat start nacos                 只启动 Nacos
dev.bat start gateway               只启动网关
dev.bat stop gateway                只停网关
dev.bat start nacos,gateway         启动两个（逗号分隔，不加空格）
dev.bat stop user-service,order-service
```

可选组件：`nacos`、`gateway`、`user-service`、`product-service`、`cart-service`、`order-service`、`payment-service`

## 启动顺序

脚本按下面的顺序启动，后面的依赖前面的：

```
Nacos (8848)  →  gateway (9000)  →  各业务服务 (9001~9005)
```

Nacos 没起来时，网关和其他服务的注册都会失败，所以脚本会先等 Nacos 就绪再继续。

## 日志

启动日志在项目根的 `logs/` 目录：

| 文件 | 内容 |
| --- | --- |
| `logs/nacos.log` | Nacos 启动日志 |
| `logs/gateway.log` | 网关标准输出 |
| `logs/gateway.err.log` | 网关错误输出 |
| `logs/<服务名>.log` | 其他服务同理 |

实时查看：

```powershell
Get-Content logs\gateway.log -Wait -Tail 50
```

## 重启电脑后怎么办

脚本能检测到进程已经不在（端口没被占用、PID 对不上），直接再执行一次 `dev.bat start` 即可，不需要先清理什么。

```bat
dev.bat start
dev.bat status
```

## 脚本做了什么

**为什么用 `dev.bat` 而不是直接跑 `dev.ps1`**

Windows 默认的执行策略禁止运行 PowerShell 脚本，直接双击 `.ps1` 会报「在此系统上禁止运行脚本」。`dev.bat` 用 `-ExecutionPolicy Bypass` 调用，不用改系统设置。

**进程怎么做到脱离终端**

用 `Start-Process -WindowStyle Hidden/Minimized` 启动，子进程不挂在当前终端下。关掉 DSH 或终端，进程继续跑。

**怎么识别服务在不在**

优先查端口占用（最可靠），端口没占用时再看 `.run/` 目录里存的 PID 文件，PID 对应的进程不存在就认为已停止。

**PID 文件放哪**

项目根的 `.run/` 目录，文件名是 `<组件名>.pid`。这个目录已在 `.gitignore` 里排除。

## 常见问题

### 提示「找不到 Nacos 安装目录」

脚本会在几个位置找 Nacos：

```
%LOCALAPPDATA%\Programs\nacos
C:\nacos
<项目根>\nacos
```

都没有就会跳过。下载地址：

https://github.com/alibaba/nacos/releases/download/2.3.2/nacos-server-2.3.2.zip

**必须用 2.3.x**，3.x 与 Spring Cloud Alibaba 2023.0.3.2 不兼容。

### 提示「没有打包好的 jar」

某个服务的 `target/` 下没有 jar。先打包：

```powershell
cd src\gateway
mvn package -DskipTests
```

或者用离线模式（依赖已经下全时更快）：

```powershell
mvn -o package -DskipTests
```

### 端口被占用

```bat
dev.bat status
```

看是哪个组件占了端口。如果是上次没退干净的进程：

```powershell
netstat -ano | findstr :9000
taskkill /PID <PID> /F
```

### 启动超时

脚本等 90 秒还没检测到端口就会报超时。先看日志：

```powershell
Get-Content logs\gateway.log -Tail 50
```

常见原因：数据库连不上、Nacos 地址配错、端口冲突。

### 关掉 DSH 后服务还在跑吗

在。脚本启动的进程独立于终端。要停就用 `dev.bat stop`。

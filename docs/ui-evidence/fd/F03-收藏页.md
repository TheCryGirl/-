## 实现要点

| 项 | 实现 |
| --- | --- |
| 卡片 | 保留原 `grid-cols-2 sm:grid-cols-3 lg:grid-cols-4` 卡片网格，未改表格、未动公共 ProductCard |
| ID | 列表 key 仍为 `favoriteId`，跳转与取消收藏仍用 `productId`，未使用数组下标 |
| 失效商品 | 保留灰色遮罩、`invalidReason` 文案、置灰图片、禁止跳转 |
| 确认 | 取消收藏接 `confirmAction`，原文案「取消收藏「标题」？」；取消/ESC 不发请求、不提示失败 |
| 忙状态 | 按 `productId` 记录当前取消项，只有该项按钮 loading，其他删除按钮禁用，商品卡跳转不受影响 |
| 成功 | `isOk` 判断 Result<Void> 后提示「已取消收藏」并按原逻辑刷新；删除当前页最后一条且 `page > 1` 时先回上一页 |
| 失败 | 业务/HTTP 失败均提示后端 message，保留原列表，不先删本地数据 |
| 三态 | 首次加载用 `el-skeleton`；加载失败用 `el-result` + 重试，不与空态混用；成功为空用 `el-empty` + 「去逛逛」；失败时头部不显示数量 |
| 分页 | 原自定义上一页/下一页改为 `el-pagination`（prev/pager/next），页容量仍为 12，总数与页码逻辑不变 |
| testid | `favorites-remove-<productId>`、`favorites-retry`、`favorites-pagination` |
| 未改 | API、store、router、公共组件、依赖与锁文件、其他页面 |

## 验证记录

本地 mock 提供 16 条收藏（含 1 条失效），仅用于开发验证。

| 场景 | 操作 | 结果 |
| --- | --- | --- |
| 生产构建 | `pnpm run build` | 通过（vite 8.3.4，971ms） |
| 初始渲染 | 打开 `/favorites` | 共 16 件，第一页 12 张卡，失效商品有「商品已下架」遮罩；分页 2 页；控制台无告警；见 [1440 截图](images/f03-favorites.png) |
| 取消确认 | 点「取消收藏」后点「取消」 | 弹窗文案正确；无 DELETE 请求、列表不变、无失败提示 |
| 确认取消 | 再次点「取消收藏」并确认 | `DELETE /api/favorites/p-001` 200 → 重新 GET，总数 15，提示「已取消收藏」 |
| 末页回退 | 第 2 页依次删除至最后一条 | 删除过程中 GET 均为 `page=2`；最后一条删除后下一请求为 `page=1`，共 12 条，分页自动隐藏 |
| 失效商品 | 点击「记忆棉靠枕」卡片 | 路由仍为 `/favorites`，不进入详情 |
| 正常跳转 | 点击「机械键盘 87 键」卡片 | 路由为 `/products/p-002`，商品 ID 正确 |
| 加载失败 | mock 返回 500 | 显示 `el-result`「加载收藏夹失败」+ 后端文案 + 重试；空态不出现；头部数量隐藏；见 [截图](images/f03-favorites-error.png) |
| 失败重试 | 恢复 mock 后点「重试」 | 重新 GET 成功，恢复 16 条卡片 |
| 空态 | mock 返回空列表 | 显示 `el-empty`「收藏夹还是空的」+「去逛逛」，与失败态明显区分；见 [截图](images/f03-favorites-empty.png) |
| 写失败 | mock 对 DELETE 返回 500 | 提示「取消收藏失败（模拟）」，总数与卡片不变 |
| 响应式 | 360/768/1920 宽 iframe 实测 | 主内容分别无溢出（`main.scrollWidth` 345/753/1280）；360 下卡片两列、时间换行正常；见 [360 截图](images/f03-favorites-360.png) |
| 控制台 | 三个页面加载与操作 | 仅 Vite 连接日志，无 Vue 告警或报错 |

## 未测与风险

- 未接真实 favorite 服务：真实分页边界、商品失效字段、401 未实测。
- 无头/隐藏视口下 Element Plus 弹窗离场动画不结束，DOM 会暂时残留；已用 DOM 点击与网络请求验证行为，真实浏览器动画待评审复核。
- 连续快速翻页的请求竞态与原实现一致，未额外加请求序号。
- 360px 下公共 `AppHeader` 自身横向溢出（文档 `scrollWidth` 394），属于既有共享文件问题；本页主内容未溢出，未改 AppHeader。

## 二、改造内容

| 项 | 改造前 | 改造后 |
| --- | --- | --- |
| 表格 | 手写 `<table>` + 自定义 class | `el-card` 包 `UiTable`（内部 `el-table`） |
| 商品列 | `<img>` + 标题 | `el-image`（`fit=cover`）+ 标题/副标题（长文本 `truncate`） |
| 价格列 | `(cents/100).toFixed(2)` 直出 | `formatMoney`：`Number.isFinite` 兜底，非法值显示 `-` |
| 状态列 | 手写 `statusText` / `statusClass` 映射 | `constants/status.js` 的 `PRODUCT_STATUS_MAP` / `PRODUCT_STATUS_TAG` + `statusText` / `statusTag` |
| 操作 | 裸 `<button>` / `<RouterLink>` 直接提交 | `el-button link` + `confirmAction` 二次确认 + `isOk` 判断 + `operatingId` 防重复 |
| 加载 / 空 / 失败 | 三态混在一个 `v-if` 链，失败与空态都显示「暂无商品」 | 失败走 `el-result status="error"` + 重试；空态走 `emptyText="暂无商品"`；加载走 `UiTable :loading` |
| 反馈 | 页面顶部一行红字 | `showSuccess` / `showError(resolveErrorMessage(...))` |
| 页面标题 | 自带 `<h1>商品管理</h1>` | 删除，改由路由 `meta.title` 决定（规范 2.2） |
| 详情/编辑跳转 | `RouterLink` | `router.push` + 行内 `data-testid`（标识用 `productId`，不用数组下标） |

**保留的行为**（对照任务书 T01「必须保留」）：

- 上下架仍是**点击即提交的按钮**，没有改成 element 的 switch 自动提交；
- 原操作条件不变：`ON_SALE` 才显示「下架」、`OFF_SHELF` 才显示「上架」、`REJECTED` 显示「请编辑后重新提交审核」；
- 接口不变：`GET /products/mine`、`PUT /products/:id/status`（均为 `productApi` 既有方法）。

## 三、验收自测（对照任务书第 4 节）

| 场景 | 操作 | 期望 | 结果 |
| --- | --- | --- | --- |
| 商品空 | 新卖家无商品 | 显示「暂无商品」，不是错误提示 | 由 `empty-text` + `isEmpty` 分支保证（静态检查通过） |
| 请求失败 | 停后端后进入页面 | 显示 `el-result` 错误 + 重试按钮，重试不发筛选参数、不改页面状态 | 代码路径已核对；**待真实后端联调截图** |
| 商品编辑跳转 | 点行内「编辑」 | 跳 `/seller/products/:id/edit`，`:id` 为所点行 `productId` | `router.push({ name:'seller-product-edit', params:{ id: row.productId } })` |
| 上下架 | 点「下架」→ 确定 | 一次 `PUT /status`，成功 toast + 刷新列表；点「取消」不发请求 | 取消分支 `if (!ok) return` 在请求之前 |
| 重复点击 | 连续点两次「下架」 | 第二次被 `operatingId` 拦住，只发一次请求 | 按钮 `:loading="operatingId === row.productId"` |
| 业务失败 | 后端返回 `code!==0` | 只弹后端 message，列表不变（无假成功） | `isOk(data)` 判断后再 `showSuccess` |
| 权限 | 买家访问 `/seller/products` | 仍由路由 `meta.role` 拦下，未改路由 | 路由文件未改动 |
| 响应式 | 360 / 768 / 1440 | 卡片内不出现整页横向溢出 | 表格由 `UiTable` 内部滚动（`scrollX` 默认 true）；**待浏览器实测截图** |

## 五、手动验证步骤（有环境时照此执行）

1. `VITE_GATEWAY_TARGET=http://localhost:19000 pnpm dev`，用卖家账号登录；
2. 访问 `/seller/products`：确认加载态 → 列表渲染（图片、价格两位小数、状态 tag）；
3. 点「编辑」：确认地址栏 `productId` 与所点行一致；
4. 点「下架」→ 弹确认框 → 先点「取消」，确认 Network 无请求；再点「确定」，确认只有一次 `PUT /products/{id}/status` 且提示成功、行状态刷新；
5. 停掉后端后刷新页面：确认出现错误态与「重试」按钮，且不显示「暂无商品」；
6. 浏览器缩到 360 宽：确认表格在卡片内部横向滚动，页面整体不横向溢出。

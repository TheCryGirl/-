# 成员材料填写说明（Excel 版）

> 填 `成员材料填写表.xlsx`，一人一页，填完即可。统计总表自动汇总，不用动。

---

| 子表 | 是谁的 | 填什么 |
| --- | --- | --- |
| `0-统计总表` | **不用填** | 全部公式自动汇总 |
| `1-哭女` | 哭女 | 自己那页 |
| `2-王瑞` | 王瑞 | 自己那页 |

---

## 二、每人那页填三块

### 1. 身份确认（表格上部）

- **真实姓名**：填全名，会写进报告
- **本人确认已填写**：下拉选「是」

### 2. 个人总结（中部橙色大格）

已预填 AI 初稿（内容基于你的真实提交记录，可直接用）。两个选择：

- **直接用** → 「是否自行改写」选「否-沿用初稿」
- **自己改** → 改橙色格里的文字 → 选「是-我重写了」

### 3. 互评打分（下部表格）

给**另外 4 人**打分（列表里就是那 4 个人，没有你自己）：

| 列 | 填法 |
| --- | --- |
| 工作态度 / 系统设计 / 系统实现 / 系统测试 | 各填 0–25 整数，超范围会标红并拒绝 |
| 合计 | **公式自动算**，不用填 |
| 一句话理由 | 必填。要具体到事，不要「态度积极配合良好」这类空话 |

**评分口径**：23–25 超出预期 / 20–22 符合预期 / 17–19 基本符合 / 14–16 低于预期。
**不要四个人全打一样的分**——全 25 等于没评。

## 三、统计总表（不用填，但要会看）

| 区块 | 看什么 |
| --- | --- |
| 一、成员身份 | 姓名和确认是否收齐 |
| 二、互评明细矩阵 | 行=评分人、列=被评人，20 格；谁没交，整行空白 |
| 三、每人汇总 | 每人收到份数、四个维度均分、平均总分、最高最低 |
| 贡献系数 | **唯一要填的地方**（K 列，5 个数），填完全组平均须 = 1.0，否则旁边会显示「不通过」并告诉你差多少 |
| 四、总体完成度 | 五项进度：姓名、确认、总结、打分、系数 |

## 四、怎么交

1. **各自下载 → 填自己那页 → 发回群里**，组长合并；或者
2. 共享编辑（腾讯文档/飞书导入此 xlsx 也行，公式兼容）

**注意**：如果分开各自填，合并时把不同版本的同一子表页对照着拷贝数值即可，统计表公式不用重建。

---

## 五、贡献系数怎么定

体现工作量差异，五项平均必须 = 1.0。例如：

```
1.2 + 1.1 + 1.0 + 0.9 + 0.8 = 5.0  ✓
```

全填 1.0 也算通过，但体现不出差异。建议结合 219 次提交分布和实际分工商量着定。

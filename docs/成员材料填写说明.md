## 二、几个关键规则

### 1. 只能评别人，不能评自己

表单已按「每人评 4 人」的结构排好，共 **20 份评分**。你打开自己的段落，里面列的全是其他 4 位。

### 2. 评分口径

每项 0–25 整数，四项合计 100。

| 区间 | 含义 |
| --- | --- |
| 23–25 | 明显超出预期 |
| 20–22 | 符合预期 |
| 17–19 | 基本符合，有短板 |
| 14–16 | 低于预期 |
| 0–13 | 明显不达标 |

**不要所有人都打一样的分。** 全部 25 分等于没打分，评审一眼能看出来。

### 3. 一句话理由必须具体

下面这种是废的：

> 「工作认真，态度积极，配合良好」

下面这种才有用：

> 「订单超时取消与主动取消并发时，他抓出了库存重复释放的竞态，并写了并发测试覆盖」

### 4. 贡献系数

体现工作量差异，**五项算术平均必须等于 1.0**。

有高有低的例子（平均 = 1.0）：

```
1.2 + 1.1 + 1.0 + 0.9 + 0.8 = 5.0  ✓
```

或者全填 1.0 也算通过，但那样体现不了差异，看你们组怎么定。

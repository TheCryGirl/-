## 重跑验证

在仓库根目录执行。使用 JDK 17、Maven、Node.js 22.12+ 或 24 和 pnpm；测试不需要在已有演示库中导入数据。

```powershell
Push-Location src
mvn -B verify
Pop-Location
Push-Location src/web
pnpm install --frozen-lockfile
node --test tests/*.mjs
pnpm build
Pop-Location
powershell -NoProfile -File src/scripts/tests/demo-launcher.tests.ps1
```

各命令应退出 `0`。后端详细结果在各模块的 `target/surefire-reports/`，前端测试以 Node 汇总为准。实机冒烟另按[启动指南](演示一键启动.md)建独立空库、启动服务后导入演示账号；不要把 H2 集成测试、真实 MySQL 冒烟和历史 Docker 压测混为一次验证。

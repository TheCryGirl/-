## 一、一句话概括

基于 Nacos + Spring Cloud Gateway + 六微服务 + Vue 3 的在线商城。后端功能完整、测试与部署已跑通；前端正在从手写 Tailwind 迁移到 Element Plus，基础层与卖家端 6 页已完成，剩余 23 个业务页面待改造。

## 二、架构与端口

```
浏览器
  │
  ▼
gateway :9000          JWT 统一鉴权，注入 X-User-Id / X-User-Role，生成 TraceId
  │
  ├── user-service     :9001   mall_user      注册登录、JWT、角色、地址、头像
  ├── product-service  :9002   mall_product   商品、SKU、库存预占/确认/释放、分类、库存预警
  ├── cart-service     :9003   mall_cart      购物车
  ├── order-service    :9004   mall_order     订单、状态机、幂等、评价、审计日志、平台配置
  └── payment-service  :9005   mall_payment   支付、回调、退款、售后、对账任务

Nacos  :8848   注册发现 + 配置中心（dataId: mall-platform.yml）
MySQL  :3306   一服务一库
```

**Docker 部署时端口映射不同**：网关 19000、业务服务 19001–19005、Nacos 18848、MySQL 13306。

技术栈：JDK 17 / Spring Boot 3.2.5 / Spring Cloud 2023.0.1 / SCA 2023.0.3.2 / MyBatis / OpenFeign / MySQL 8.0 / Vue 3.5 / Vite 8 / Tailwind 4 / Element Plus 2.14。

## 五、环境启动要点

**WSL 下 dockerd 必须用独立进程启动**。用 systemd 的 socket 激活方式（`-H fd://`）会导致 daemon 周期性重启、容器反复重启，表现为容器永远显示「Up 几秒」：

```bash
wsl -d Ubuntu -u root -- bash -c 'systemctl stop docker.service docker.socket; \
  setsid nohup /usr/bin/dockerd -H unix:///var/run/docker.sock \
  --containerd=/run/containerd/containerd.sock > /var/log/dockerd-standalone.log 2>&1 < /dev/null &'
sleep 12

cd src/docker
docker compose -f docker-compose.yml -f docker-compose.verify.yml up -d
```

前端连 Docker 网关（注意不是默认的 9000）：

```bash
cd src/web
VITE_GATEWAY_TARGET=http://localhost:19000 pnpm dev
```

详细步骤见 [README](../README.md) 与 [本地启动指南](../src/docs/本地启动指南.md)。

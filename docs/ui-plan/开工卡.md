## 三、五个不许

1. **不许** `import { ... } from 'element-plus'`（模板里直接写 `<el-button>` 就行，会自动引入）
2. **不许** `window.confirm` / `window.alert`（用 `confirmAction`）
3. **不许** `@/` 开头的路径（项目没配别名，用相对路径）
4. **不许**改 `src/api/`、`src/stores/`、`src/router/`、`src/style.css`、`src/components/ui/`、`package.json`、`pnpm-lock.yaml`
5. **不许**改别人负责的文件

## 四、照抄的模板

看 [src/web/src/views/_StandardPage.vue](../../src/web/src/views/_StandardPage.vue)，它演示了全部正确写法：

- 筛选区（不加卡片）+ `el-card` 包表格 + `UiTable`
- 加载 / 空 / 失败三态分离
- `isOk()` 判成功
- `confirmAction` 二次确认
- `usePagination` 分页
- 状态文案从 `constants/status.js` 取
- 列表读 `data.list` / `data.total`

**直接复制结构，改字段名和接口名就行。**

## 五、必须记住的 5 个写法

```js
// 1. 成功判断：读接口写接口都用 isOk
const { data } = await userApi.list(params)
if (!isOk(data)) { loadError.value = data?.message || '加载失败'; return }
const payload = unwrapResult(data)
list.value = payload?.list ?? []    // 不是 records
total.value = payload?.total ?? 0

// 2. 金额：后端是分
const formatMoney = (c) => `¥${(Number(c) / 100).toFixed(2)}`

// 3. 状态文案：从 constants 取，不要自己写
import { ORDER_STATUS_MAP, statusText } from '../constants/status'
statusText(ORDER_STATUS_MAP, row.status)

// 4. 危险操作：确认后立即 return
const ok = await confirmAction({ message: '确定删除？', danger: true })
if (!ok) return

// 5. 提交防重
if (submitting.value) return
submitting.value = true
try { /* ... */ } finally { submitting.value = false }
```

## 八、环境启动

```bash
# dockerd 必须独立进程启动，不要用 systemctl
wsl -d Ubuntu -u root -- bash -c 'systemctl stop docker.service docker.socket; \
  setsid nohup /usr/bin/dockerd -H unix:///var/run/docker.sock \
  --containerd=/run/containerd/containerd.sock > /var/log/dockerd-standalone.log 2>&1 < /dev/null &'
sleep 12

cd /opt/mall/src/docker && docker compose -f docker-compose.yml -f docker-compose.verify.yml up -d
# 等约 1 分钟

cd src/web && VITE_GATEWAY_TARGET=http://localhost:19000 pnpm dev
```

# F01 登录页 Element Plus 改造（试点）

- 任务：F01 Login，见 [fd 任务书](../../ui-plan/fd.md)
- 分支：`feature/ui-fd-login`（基于 main `877e6e8`，**未合并**）
- 改动文件：仅 `src/web/src/views/Login.vue`；证据目录为本目录

## 实现要点

| 项 | 实现 |
| --- | --- |
| 表单 | `el-form` + `el-form-item`（label 在上），`el-input` 绑定原变量 |
| 密码 | `show-password`，只切换可见性，不改值 |
| 提交 | 按钮 `:loading`，提交期间禁止重复触发；Enter 与按钮共用 `submit` |
| 错误 | 空字段显示原文案「请输入账号和密码」；业务/HTTP 失败用 `el-alert` 就地展示 |
| 保持不变 | 原字段、校验规则与文案、`userApi.login` 调用、`setLogin`、`redirectTarget` 跳转、去注册链接 |
| testid | `login-account`、`login-password`、`login-error`、`login-submit` |
| 未改 | API、store、router、公共组件、依赖与锁文件、其他页面 |

## 验证记录

| 场景 | 操作 | 结果 |
| --- | --- | --- |
| 生产构建 | `pnpm install --frozen-lockfile` + `pnpm build` | 通过（vite 8.3.4，984 ms） |
| 初始渲染 | 打开 `/login` | 通过，无控制台告警；见 [截图](images/f01-login-initial.png) |
| 空提交 | 不填直接点「登录」 | 显示「请输入账号和密码」，无 XHR |
| 网络失败 | 填写后点「登录」（dev 代理无网关，返回 502） | 发出 `POST /api/users/login`，页面就地显示失败；控制台仅该 502，无 Vue 告警 |
| Enter 提交 | 在密码框触发 Enter | 合成 `keyup(Enter)` 验证会走同一 `submit` 并发出请求；自动化浏览器无法注入真实按键，真机 Enter 待评审复核 |
| 布局 | 初始截图宽度 819px | 无横向溢出；360/768/1440/1920 未逐一实测 |

## 未测与风险

- 真实登录成功、`redirectTarget` 跳转未测：本地未启动网关与后端。
- 401、慢网重复点击、断网重试未做浏览器实测；重复提交已由 `loading` 状态与入口守卫拦截。
- 本页为试点，F02–F04 待风格评审通过后再实施。

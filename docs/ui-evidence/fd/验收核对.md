## 五、未测与风险

1. 未接真实 user/favorite/history 服务：真实业务错误码、401、超时、分页边界、失效字段待联调复核。
2. F01 真实登录成功与 `redirectTarget` 跳转未测；360/768/1440/1920 未逐一实测（F02–F04 已测）。
3. Enter 由合成键盘事件验证；真实系统键盘/输入法行为待评审复核。
4. 360px 下公共 `AppHeader` 自身横向溢出（文档 `scrollWidth` 394）为既有共享问题，本次未改，主内容无溢出。
5. 隐藏/无头视口下 Element Plus 弹窗离场动画不结束，DOM 暂时残留；行为以网络请求与列表状态验证，真实浏览器动画待复核。
6. 快速连续翻页的请求竞态与原实现一致，未额外增加请求序号。
